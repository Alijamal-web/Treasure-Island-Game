# Treasure Island Game

## About the Project

Treasure Island is a text-based adventure game developed using Python. The player's mission is to explore the island, make the right decisions, and find the hidden treasure.

Each choice leads to a different outcome, and one wrong decision can end the adventure.

## Features

- Interactive text-based gameplay.
- Multiple decision-making scenarios.
- ASCII art introduction.
- Different game endings.
- Nested conditional statements.
- User input handling.

## Technologies Used

- Python
- Built-in input() and print() functions

## How to Run

1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Run the following command:

`python main.py`

## How to Play

1. Start your adventure on the island.
2. Choose left or right at the crossroads.
3. If you choose left, decide whether to wait for a boat or swim across the lake.
4. After reaching the island, choose one of the three doors: red, yellow, or blue.
5. Make the correct decisions to discover the hidden treasure and win the game!
